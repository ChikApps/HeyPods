**הרכבה בזמן ריצה** (`ART.scene(fam, {l, r, led})`): לכל אוזנייה מצב `case` (בשקע: נחתכת בשפת השקע) או `out` (באוזן/בחוץ: מצוירת מסובבת 9° ליד הקופסה, עם צל משלה; השקע נשאר חור כהה). הכי פשוט ב-WPF: 3 שכבות `DrawingImage` (קופסה, אוזנייה בשקע ×2, אוזנייה בחוץ ×2) עם `Visibility` לפי המיקום. שמאל = ימין עם `ScaleX=-1`, **חוץ מהאותיות L/R** (טקסט נפרד, לא משוקף).
**סדר פיזי:** שמאל בצד שמאל של הציור, ימין בימין, הקופסה באמצע. שורת האחוזים מתחת באותו סדר (שורה ב-LTR, טקסט בתוכה RTL).

**מתחת לכל חלק:** טבעת עם האחוז במרכז · שם החלק (6px מתחת לטבעת) · בחלון הראשי גם גלולת מיקום. 20% ומטה: קשת ומספר low · לא ידוע: מסלול בלבד (בלי קשת) ו-"--" בצבע sec · נתון ישן: קשת ומספר stale.

## 4א. טבעת הסוללה ב-WPF (Path + ArcSegment)
| איפה | קוטר D | עובי S | אחוז בפנים | ברק |
|---|---|---|---|---|
| חלון קופץ, אשף צעד 2 | **60** | **4** | 15 Semibold | 9×12.6 |
| חלון ראשי | **56** | **4** | 14 Semibold | 9×12.6 |
| (רק בלוח המצבים בעיצוב) | 44 | 3 | 10 Semibold | 7×9.8 |

- **100%** = 3 ספרות: האחוז קטן ב-20% (15→12, 14→11.2) והברק 1px קטן יותר, כדי ש"⚡100%" יישאר בתוך הטבעת. נמדד: רוחב התוכן ≤ D−2S−3.
- **רדיוס הקו:** `r = (D − S) / 2` (הקו מצויר על המרכז שלו, כך שהטבעת לא חורגת מ-D). מרכז: `c = D / 2`.
- **כיוון:** מתחילה ב-12 (למעלה) ומתמלאת **עם כיוון השעון**. ⚠️ לשים על ה-Grid של הטבעת `FlowDirection="LeftToRight"`, אחרת בחלון RTL ה-Path משתקף והטבעת מתמלאת הפוך.
- **קצוות:** `StrokeStartLineCap="Round"` ו-`StrokeEndLineCap="Round"`. ב-0% לא מציירים קשת בכלל (אחרת נשארת נקודה).

**הנוסחה לזווית** (p = 0..100):
```
θ = p / 100 × 360°                     (ברדיאנים: θ = p / 100 × 2π)
StartPoint = (c, c − r)                 ← שעה 12
Point      = (c + r·sin θ, c − r·cos θ) ← סוף הקשת
Size = (r, r) · IsLargeArc = p > 50 · SweepDirection = Clockwise
```
דוגמה, חלון קופץ 70%: c=30, r=28, θ=252° → Point = (30+28·sin252°, 30−28·cos252°) = **(3.37, 38.65)**, IsLargeArc=True.

**100% = עיגול מלא:** ArcSegment לא יכול לצייר 360° (התחלה = סוף → לא מצויר). ב-100 משתמשים ב-`EllipseGeometry` (Center=c,c · RadiusX=RadiusY=r), או ב-p ≥ 99.99 מציירים עד 359.99°.

```xml
<Grid Width="60" Height="60" FlowDirection="LeftToRight">
  <Ellipse Margin="2" Stroke="{DynamicResource RingTrackBrush}" StrokeThickness="4"/>   <!-- מסלול: Margin = S/2 -->
  <Path Stroke="{Binding RingBrush}" StrokeThickness="4"
        StrokeStartLineCap="Round" StrokeEndLineCap="Round"
        Data="{Binding Level, Converter={StaticResource ArcConverter}, ConverterParameter=60|4}"/>
  <StackPanel Orientation="Horizontal" HorizontalAlignment="Center" VerticalAlignment="Center">
    <Path x:Name="Bolt" Visibility="{Binding IsCharging, Converter=...}" .../>  <!-- ברק, אותו צבע כמו הקשת -->
    <TextBlock Text="{Binding LevelText}" FontSize="15" FontWeight="SemiBold"/> <!-- "70%" / "--" -->
  </StackPanel>
</Grid>
```
```csharp
// ArcConverter: Level (int?) → Geometry.  null או 0 → Geometry.Empty
double c = D / 2, r = (D - S) / 2, a = p / 100.0 * 2 * Math.PI;
if (p >= 100) return new EllipseGeometry(new Point(c, c), r, r);
var fig = new PathFigure { StartPoint = new Point(c, c - r), IsClosed = false, IsFilled = false };
fig.Segments.Add(new ArcSegment(new Point(c + r * Math.Sin(a), c - r * Math.Cos(a)),
    new Size(r, r), 0, p > 50, SweepDirection.Clockwise, true));
var g = new PathGeometry(new[] { fig }); g.Freeze(); return g;
```
המקור בעיצוב: `make/ui.js` → `ringPath()` / `ring()` (אותה נוסחה בדיוק).
